# Exercicios React - Desenvolvimento de Software para WEB

Projeto feito para a disciplina de Desenvolvimento de Software para WEB (UGB).

Cada exercicio esta em uma branch:
- feat-exercicio1: caixa de mercado
- feat-exercicio2: jogo de adivinhacao
- feat-exercicio3: pedra, papel e tesoura

Para rodar: npm install e depois npm run dev
